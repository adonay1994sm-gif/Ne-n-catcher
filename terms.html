Términos de uso

Última actualización: 3 de agosto de 2026.

Neon Catcher se ofrece como entretenimiento. Las puntuaciones y el progreso se guardan localmente y pueden perderse al borrar los datos del navegador o desinstalar la aplicación.

Publicidad y recompensas

Esta base usa anuncios nativos de prueba y una simulación web de control de calidad. En una versión con publicidad real, la recompensa solo se concederá cuando el proveedor confirme el evento recompensado.

Uso aceptable

No se permite manipular anuncios, generar clics artificiales, automatizar impresiones ni alterar la aplicación para obtener recompensas fraudulentas.

Estado de la compilación

V6.5 es una versión técnica verificada, no la versión contractual definitiva para App Store. La identidad legal, el contacto, la clasificación y las condiciones comerciales se cerrarán antes del lanzamiento público.
